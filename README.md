# Pocket Cosmos: Special Lumbit Edition

Area 1 of Pocket Cosmos, a monster-catching JRPG with toon shading, in your browser. **Play it at https://demidummy.github.io/pocket-cosmos-web/**

Keyboard: arrows to move, Z or Space to confirm, X or Escape to go back, Enter for the menu, Shift to run. A gamepad
works too.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
